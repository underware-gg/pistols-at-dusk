# scripts/

Shared code and CLIs for the source-side ingest tooling, the runtime/composition harness, and the bridge between them. This directory is indexed from the functional layer at [docs/functional/README.md](../docs/functional/README.md).

## Modules

- [source_ingest.py](source_ingest.py) — source-side ingest and review CLI: family inspection, source-layout detection, source-cell lookup, semantic review-pack export, collection review-pack export, and ingest/audit checks. Use this when the task starts from a raw sheet or reference image rather than from a composed scene.
- [source_manifests.py](source_manifests.py) — staged source-side pack / tileset / logical-tilesheet manifest loader and validator for the current ingest model. This module is intentionally ingest-only; the runtime should continue to consume compatibility/library units rather than these manifests directly.
- [source_manifest_bridge.py](source_manifest_bridge.py) — one-way transitional adapter from the staged source manifests into the current family-backed compatibility pipeline. Keeps source-side module identity, module context, render traits, and documented hints explicit while promoting the runtime-relevant subset onto the `TileFamily` / `TileLibraryUnit` boundary.
- [reference_grid.py](reference_grid.py) — reference-sheet slicing helper: apply a solved render-grid transform to a screenshot/reference image, optionally trim it to one or more relevant tiled regions, keep or drop partially visible edge cells, then emit a full-cell crop, base-tile contact sheet, and padded guide overlays for tile-by-tile review.
- [reference_tile_match.py](reference_tile_match.py) — reference-tile matcher: compare recovered reference cells against a family variant source sheet, with the same relevant-region and exclusion-box controls as the slicer, reporting blank cells, exact matches, tiered guessed matches, and optional manual review overrides.
- [minimal8_harness.py](minimal8_harness.py) — runtime/composition harness CLI: layout rendering, scene-runtime export, pattern scaffolding, kit/bootstrap helpers, and project-specific runtime callbacks for the scene DSL and entity expansion.
- [tile_families.py](tile_families.py) — generic tile-family loader and query model: family / cluster / tile catalogs, alias resolution, address parsing, construction loading and validation. Also exposes `TileLibraryUnit`, a self-contained runtime-facing compatibility view with promoted runtime metadata, and `TileLibraryRegistry`, the runtime registry over loaded units.
- [scene_templates.py](scene_templates.py) — scene template DSL: file-backed loading, validation, expression evaluation, data-mode scene expansion, cycle detection across `place_scene`.
- [scene_rules.py](scene_rules.py) — environment-specific scene-rules loader and validator for weighted stamp/entity/scene candidate catalogues.
- [prototype_output.py](prototype_output.py) — render pipeline output helpers (staged writes, archive rotation on diff).

## Tooling

- [check_pyright.sh](check_pyright.sh) — type-check entrypoint. Required to pass before committing typed engine changes.
- [check_coverage.sh](check_coverage.sh) — coverage entrypoint for the shared Python scripts.
- `python3 scripts/source_ingest.py --help` — source-side review and ingest entrypoint. Use this for family inspection, source-layout detection, source-sheet cell lookup, review-pack export, and ingest/audit validation.
- `python3 scripts/source_ingest.py inspect-source-cell prototypes/minimal8-harness/project.minimal8.json --tileset 'minimal8@2bit_colored_bg' --sheet-col 21 --sheet-row 4` — inspect one zero-based source-sheet cell through the authoritative ingest map. This is the safest way to answer “what is the third tile from the left in the top section of the second source-sheet column?” because it reports the source-layout region/cluster context and any mapped family tile in one place instead of forcing you to infer that join from ad hoc review sheets.
- `python3 scripts/reference_grid.py --help` — extract a reference image onto a stable tile grid once you know either the render-space origin/cell size or the exact tiled-body `span_box`; optionally normalize that raw span onto a uniform cell size for matching/review, constrain the solve to relevant tiled regions, ignore headings or other excluded zones, decide whether partially visible edge cells stay in the ingested sheet, and choose between `separated` (default) or `overlay` guide-line rendering.
- `python3 scripts/reference_tile_match.py --help` — match extracted reference cells against a family variant source sheet once the grid transform is known, using the same origin/pitch-or-span solve model plus the same optional normalized ingest surface, relevant-region controls, and exclusion controls as the slicer. The matcher now classifies cells as `blank`, `exact`, `high_confidence`, `best_guess`, or `unresolved`, records config-driven `reviews` separately from machine confidence, and reports both raw `mask_iou` and a conservative trimmed logical-mask rescue for reference cases where the motif is right but whitespace placement inside the cell has drifted.
- Both tools also accept `--config <json>` so committed reference-ingest state can live in repo and be rerun without retyping the transform. Current Minimal 8 examples live at [prototypes/minimal8-harness/reference-transforms/reference-overworld-island-title-screen.json](../prototypes/minimal8-harness/reference-transforms/reference-overworld-island-title-screen.json) and [prototypes/minimal8-harness/reference-transforms/reference-polychrome-temple-courtyard.json](../prototypes/minimal8-harness/reference-transforms/reference-polychrome-temple-courtyard.json). The slicer also saves the trimmed ingest guide beside the source image with a `--guide` suffix and, when normalization is enabled, writes `*_normalized_body.png` plus the same ingest-sheet overlays into the chosen output directory so the solved sheet can be reused during manual ingest or scene reconstruction.
