# Pistols at Dusk

Pistols at Dusk is a rogue-like RPG game using the Pistols Dueling Engine :TM:, set in the Pistols at Dawn universe. This repo also includes prototypes of tileset and tile-based layout tooling, ingestion, semantic tile catalogs, and grid-based scene-composition.

If it exists, ALWAYS read `AGENTS.local.md` for tracked machine-specific overrides when present.

Keep this file minimal and route to other docs with links; working rules, repo structure, and verification expectations live in the contributor layer.
