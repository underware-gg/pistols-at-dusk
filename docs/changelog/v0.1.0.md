# v0.1.0 — 2026-05-12

**Ship the Minimal 8 harness as the repo's first public baseline**

v0.1.0 is the first public snapshot of Pistols at Dusk. The shipped surface is
still tooling-led rather than full game runtime: this release publishes the
Minimal 8 harness, the canonical family package, the authored scene/template
stack, and the contributor/documentation contract around them.

- The first public harness CLI supports family bootstrap, layout rendering, family inspection, review-pack export, collection-review export, scene-runtime inspection, semantic queries, and public tile-pack export.
  - Important identifiers: `scripts/minimal8_harness.py`, `prototypes/minimal8-harness/project.minimal8.json`
- The core runtime model now covers semantic tile catalogues, constructions, data-mode scene expansion, deterministic slot population, and staged/archived output publishing.
  - Important identifiers: `scripts/tile_families.py`, `scripts/scene_templates.py`, `scripts/scene_rules.py`, `scripts/prototype_output.py`
- The repo ships a canonical Minimal 8 package plus authored templates, rulesets, and sample layouts that exercise the harness rather than just raw engine code.
  - Important identifiers: `prototypes/minimal8-harness/tile-families/minimal8/`, `prototypes/minimal8-harness/scene-templates/`, `prototypes/minimal8-harness/scene-rules/`, `prototypes/minimal8-harness/layouts/`
- The first public baseline ships with an executable verification contract for the harness, covering behavioural tests, typed-entrypoint checks, and coverage tooling.
  - Important identifiers: `tests/test_tile_families.py`, `tests/test_minimal8_harness.py`, `tests/test_scene_expansion.py`, `tests/test_prototype_output.py`, `scripts/check_pyright.sh`, `scripts/check_coverage.sh`
- The first public documentation surface and release contract are in place across the four doc layers, the repo landing pages, and the version/changelog package.
  - Important identifiers: `docs/user/README.md`, `docs/functional/README.md`, `docs/architecture/README.md`, `docs/contributor/README.md`, `README.md`, `VERSION`, `docs/CHANGELOG.md`
