# v0.1.2 — 2026-05-18

**Extract a self-contained runtime tile library boundary**

v0.1.2 lifts a self-contained runtime tile library boundary out of `scripts/minimal8_harness.py` and into `scripts/tile_families.py`. The runtime surface is now the only path the harness uses to read tile data; source-family access stays inside the loader, guarded by behavioural tests so the boundary cannot quietly leak back into the harness.

- A new runtime tile library object owns layout, family-ref resolution, and semantic queries; the harness consumes it instead of reaching into source-family state directly.
  - Important identifiers: `scripts/tile_families.py`, `scripts/minimal8_harness.py`
- Source-family access is constrained to the loader. The harness gets a clarified accessor; tests assert that the runtime surface does not expose source-only attributes, so the boundary stays clean as the surrounding code evolves.
  - Important identifiers: `tests/test_minimal8_harness.py`, `tests/test_scene_expansion.py`
- The architecture, functional, and scripts indexes are updated so the runtime/source split is documented where contributors look first.
  - Important identifiers: `docs/architecture/README.md`, `docs/functional/README.md`, `scripts/README.md`
