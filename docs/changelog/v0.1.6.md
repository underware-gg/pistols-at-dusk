# v0.1.6 — 2026-05-19

**Introduce staged pack, tileset, and tilesheet source manifests**

v0.1.6 starts the Phase 4 ingest-side refactor by introducing a staged source manifest hierarchy for packs, tilesets, logical tilesheets, and render variants, while keeping the runtime on compatibility/library units rather than ingest artefacts.

- A new ingest-only source manifest loader models pack provenance, ingest rules, logical-versus-render tilesheets, inherited render traits, sparse coverage, and source-layout references without changing the runtime boundary.
  - Important identifiers: `scripts/source_manifests.py`, `tests/test_source_manifests.py`
- Shared manifest helpers now carry JSON loading, required-key validation, path resolution, and bounds checks so the new source manifest loader and the existing family loader share one validation boundary.
  - Important identifiers: `scripts/_manifest_utils.py`, `scripts/tile_families.py`
- Functional documentation now records the staged source hierarchy explicitly and keeps the current Minimal 8 family package marked as the active committed ingest truth until the later migration steps land.
  - Important identifiers: `docs/functional/README.md`, `scripts/README.md`
