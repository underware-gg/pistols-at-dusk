# Stable Release Files

This folder holds one authored file per stable release promotion.

- version files under `docs/changelog/vX.Y.Z.md` describe the latest experimental shipped state on `main`
- release files here describe the later stable promotion of that same version

Current rule: one stable release file per version.

- [docs/standards/changelog.md](../../standards/changelog.md)
- [docs/contributor/release-workflow.md](../../contributor/release-workflow.md)
