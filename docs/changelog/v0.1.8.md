# v0.1.8 — 2026-05-21

**Complete the Phase 4 staged source-pack runtime boundary**

v0.1.8 finishes Phase 4 by promoting runtime-relevant source-pack metadata onto the library boundary, proving that ordinary runtime scene work stays self-sufficient after compatibility units are built, and updating the repo docs to treat staged source packs as the active ingest story.

- Runtime-facing tile-library units now carry promoted staged-pack metadata directly on the family/library boundary, including staged pack / tileset / tilesheet identifiers, shared module-context values, resolved render traits, and the notes currently promoted into runtime hints.
  - Important identifiers: `scripts/tile_families.py`, `scripts/tile_metadata.py`, `scripts/source_manifest_bridge.py`, `tests/test_source_manifest_bridge.py`, `tests/test_tile_families.py`
- Family loading now rejects intra-family alias-vs-tile-id collisions explicitly at load time instead of letting unreachable aliases slip through silently.
  - Important identifiers: `scripts/tile_families.py`, `tests/test_tile_families.py`
- Minimal 8 now has a behavioural self-sufficiency proof: after building compatibility/runtime units, deleting staged source-pack manifests and ingest/layout manifests does not break construction lookup, registry-routed ref resolution, lazy family-tileset loading, tile preview rendering, or full scene expansion.
  - Important identifiers: `tests/test_minimal8_harness.py`, `scripts/minimal8_harness.py`
- User, functional, architecture, prototype, and script-layer docs now present staged source packs as the active ingest path and the family bundle as the transitional compatibility layer, completing the Phase 4 documentation sweep.
  - Important identifiers: `README.md`, `docs/user/README.md`, `docs/functional/README.md`, `docs/architecture/README.md`, `docs/README.md`, `prototypes/minimal8-harness/README.md`, `scripts/README.md`
