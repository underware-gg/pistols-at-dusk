# v0.2.1 — 2026-05-25

**Ship reference-ingest transforms, matching, and guide tooling**

v0.2.1 turns the reference-ingest workflow into a durable repo-side surface by
checking in canonical solves for the trusted Minimal 8 references, hardening
the slicing and matching helpers around normalized ingest spans and reviewed
best-guess promotion, and making the guide and source-sheet inspection path
clear enough for another contributor to continue the work without local scratch
history.

- The reference slicer now supports committed `--config` solves, exact-span and
  normalized-cell extraction, relevant/excluded regions, one-grid guide
  rendering, and checked-in sibling guide outputs for trusted references.
  - Important identifiers: `scripts/reference_grid.py`, `tests/test_reference_grid.py`, `prototypes/minimal8-harness/reference-transforms/reference-overworld-island-title-screen.json`, `prototypes/minimal8-harness/reference-transforms/reference-polychrome-temple-courtyard.json`
- The matcher now reports semantic `blank`, `exact`, `high_confidence`, and
  `best_guess` outcomes, keeps config-driven human reviews separate from machine
  confidence, and rescues whitespace-shifted legacy reference tiles with a
  conservative trimmed logical-mask comparison instead of dropping them as
  no-match cells.
  - Important identifiers: `scripts/reference_tile_match.py`, `tests/test_reference_tile_match.py`
- The harness now exposes an authoritative `inspect-source-cell` path for
  mapping raw source-sheet coordinates back through the ingest metadata instead
  of forcing contributors to guess across semantic tile IDs and ad hoc review
  strips.
  - Important identifiers: `scripts/minimal8_harness.py`, `tests/test_minimal8_harness.py`
- Minimal 8’s durable reference-ingest artefacts are now checked in explicitly:
  the temple courtyard layout anchor, per-reference notes, committed guide
  images, and the prototype/docs routing that points contributors at those
  surfaces. Repo housekeeping also now ignores transient prototype render
  output and carries the committed Git LFS passthrough hooks alongside the
  existing distributed commit hooks.
  - Important identifiers: `prototypes/minimal8-harness/layouts/polychrome_temple_courtyard.json`, `prototypes/minimal8-harness/reference-transforms/README.md`, `resources/Super Assets 3000/references/reference-overworld-island-title-screen--guide.png`, `resources/Super Assets 3000/references/reference-polychrome-temple-courtyard--guide.png`, `.gitignore`, `tools/git-hooks/post-checkout`, `tools/git-hooks/pre-push`
