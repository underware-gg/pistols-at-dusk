# v0.1.1 — 2026-05-16

**Adopt the Underware contributor model and its enforcement**

v0.1.1 wires this repo to the shared Underware contributor model whose contract is declared in the standards layer at `docs/standards/`. Three slices ship together because they are inseparable: enforcement at the git-hook layer, contributor tooling for version and release validation, and a bootstrap and contributor-layer restructure that matches the model used by sibling Underware repos.

- The `commit-msg` and `pre-commit` hooks are the strict local enforcement of the standards layer; they reject off-standard commit subjects, README-badge drift against `VERSION`, and missing `.canary--pre-commit` receipts.
  - Important identifiers: `tools/git-hooks/commit-msg`, `tools/git-hooks/pre-commit`, `.canaries/pre-commit.md`
- A Python release tool exposes `version-check`, `release-prepare`, and `release` subcommands plus the `commit-msg-check` entrypoint used by the hook, so the same checks run from a human commit, a hook, and CI.
  - Important identifiers: `scripts/release_workflow.py`, `docs/changelog/releases/`, `docs/changelog/releases/README.md`
- Supply-chain hardening lands in two layers: a pnpm policy for the canonical install path, and an `.npmrc` defence-in-depth for the accidental `npm install` path; `pyright` is pinned to an exact `1.1.409` so transitive resolution cannot float silently.
  - Important identifiers: `pnpm-workspace.yaml`, `.npmrc`, `package.json`, `pnpm-lock.yaml`, `.gitignore`
- The bootstrap chain is restructured to the Underware shape: `AGENTS.md` is a thin router with a project-specific Safety section, `CONTRIBUTING.md` adopts the Documentation Entry Point / Start Here / Baseline Expectations layout, and `docs/README.md` and `README.md` index all five layers including the new Standards layer.
  - Important identifiers: `AGENTS.md`, `CONTRIBUTING.md`, `README.md`, `docs/README.md`
- The contributor layer gains three new docs describing the verification expectations, supply-chain policy, hook usage, canary workflow, release flow, and the per-change-type doc-update map; `working-rules.md` is trimmed to delegate to the standards layer, `repo-structure.md` lists the new top-level surfaces, and `documentation-standard.md` is updated to acknowledge the new fifth (Standards) layer.
  - Important identifiers: `docs/contributor/process.md`, `docs/contributor/release-workflow.md`, `docs/contributor/agents.md`, `docs/contributor/working-rules.md`, `docs/contributor/repo-structure.md`, `docs/contributor/documentation-standard.md`, `docs/contributor/README.md`
