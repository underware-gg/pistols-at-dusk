# v0.2.0 — 2026-05-21

**Converge project metatiles under honest composition assets**

v0.2.0 completes the post-Phase-4 metatile convergence tranche by removing the
project-level `metatiles` registry as an active harness concept, routing its
historical jobs onto patterns, constructions, and aliases/direct refs, and
recording the resulting end state explicitly in code, data, tests, and docs.

- Project loading and runtime composition now treat `patterns` as the only
  active project-scoped snippet surface, and stale project configs that still
  declare `metatiles` fail loudly at the config boundary instead of surviving
  through a hidden compatibility path.
  - Important identifiers: `scripts/minimal8_harness.py`, `tests/test_minimal8_harness.py`
- The Minimal 8 project data now finishes the real migration arithmetic:
  historical grand-door entries live only as constructions, convenience names
  like `overworld_land_undercoat` and `overworld_route_node` now resolve as
  aliases/direct refs, and the remaining 70 historical entries stay as honest
  project-scoped patterns.
  - Important identifiers: `prototypes/minimal8-harness/project.minimal8.json`, `prototypes/minimal8-harness/project.minimal8.2bit.json`, `prototypes/minimal8-harness/layouts/island_overlook.json`, `prototypes/minimal8-harness/scene-templates/tavern.json`, `prototypes/minimal8-harness/pattern-migration-inventory.md`
- Scene and runtime tests now assert the end state at the right abstraction
  level: migrated entries resolve as constructions or aliases, the tavern keeps
  its grand door as an entity instance before stamp lowering, and no normal
  runtime path depends on the removed registry.
  - Important identifiers: `tests/test_minimal8_harness.py`, `tests/test_scene_expansion.py`
- Architecture, functional, prototype, and script-layer docs now describe the
  converged composition model directly: patterns for project-scoped snippets,
  constructions for entity-shaped composites, scenes/sub-scenes for higher-order
  authored reuse, and `metatile` surviving only as the library/runtime
  construction kind.
  - Important identifiers: `docs/architecture/README.md`, `docs/architecture/construction-system.md`, `docs/architecture/source-sheet-ingestion-model.md`, `docs/functional/README.md`, `prototypes/minimal8-harness/README.md`, `scripts/README.md`
