# v0.1.4 — 2026-05-18

**Load multiple family-backed tile libraries through the registry**

v0.1.4 lets the registry from v0.1.3 hold more than one family-backed tile library at once. The harness can now load several libraries side-by-side through the same entry point, which is the precondition for cross-library family-ref routing in the next step.

- The harness loader is extended to register multiple family-backed tile libraries from project configuration, rather than a single fixed library.
  - Important identifiers: `scripts/minimal8_harness.py`
- Behavioural tests cover the multi-load shape: registration order, isolation between registered libraries, and the harness flows that consume them.
  - Important identifiers: `tests/test_minimal8_harness.py`
- Architecture and functional indexes are updated so the multi-library shape is documented alongside the registry it builds on.
  - Important identifiers: `docs/architecture/README.md`, `docs/functional/README.md`
