# v0.7.0 — 2026-05-30

**Decompose the harness and rename it to the tileset-generic engine**

v0.7.0 finishes the harness decomposition by splitting the shared base and
operator layers out of the 6.5k-line runtime module into their own files, then
renaming the slimmed core to reflect that it is tileset-generic rather than
minimal8-specific. It also closes the box-to-parametric-frame migration debt by
replacing the vestigial frame-style string toggles with explicit booleans, a
breaking scene-template contract change.

- The runtime module is now solely the scene-runtime plus CLI dispatch, with the
  shared config/render/geometry/loaders and the source-side operator surface
  living in their own modules; the dependency DAG is acyclic and
  one-directional, and all 70 layout renders stay byte-for-byte identical to the
  golden baseline.
  - Important identifiers: `scripts/harness.py`, `scripts/layout_core.py`, `scripts/source_ingest_ops.py`, `scripts/source_ingest.py`, `tests/test_harness.py`
- The runtime core is renamed to drop its minimal8 origin name now that it reads
  grid/tileset/family/constructions from project config with no baked-in
  identity; callers already aliased it as `harness`, so only the import lines
  move and behaviour is unchanged.
  - Important identifiers: `scripts/harness.py`, `tests/test_harness.py`, `scripts/source_ingest.py`
- BREAKING: the scene-template frame params `outer_style`, `stem_style`,
  `bridge_style`, and `inner_style` are removed and replaced by the explicit
  boolean toggles `stem`, `bridge`, and `inner` (default `true`); the
  optional-section gates now bind the booleans instead of treating a frame-style
  string's presence as the switch, and the redundant `*_style` args are dropped
  from the instantiating layouts.
  - Important identifiers: `prototypes/minimal8-harness/scene-templates/causeway.json`, `prototypes/minimal8-harness/scene-templates/sanctum.json`, `prototypes/minimal8-harness/scene-templates/twin_chambers.json`, `prototypes/minimal8-harness/layouts/scene_template_showcase.json`, `tests/test_scene_expansion.py`
- The living docs and command references now name the renamed module and the
  operators' true homes instead of the old "everything lives in the harness"
  framing, and ADR-0005 records the ingest/runtime split as complete while
  retaining the historical module name in landed decision records.
  - Important identifiers: `docs/architecture/decisions/0005-runtime-tile-genesis-and-provenance.md`, `docs/architecture/README.md`, `docs/functional/README.md`, `docs/user/README.md`, `prototypes/minimal8-harness/README.md`
