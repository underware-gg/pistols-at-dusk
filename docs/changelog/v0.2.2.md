# v0.2.2 — 2026-05-25

**Split source-ingest tooling from runtime harness and tighten reference matching**

v0.2.2 turns the reference-ingest follow-up work into a clearer operating
surface by separating source-sheet ingest commands from the runtime harness,
pulling the reference-grid config seam into dedicated modules, and tightening
the reference matcher so the performance and scoring fixes remain stable across
the trusted overworld and temple reference workflows.

- The source-side operator surface now has its own entrypoint, so ingest and
  review work starts from a module that names the right domain instead of
  hiding under the runtime harness CLI.
  - Important identifiers: `scripts/source_ingest.py`, `tests/test_source_ingest.py`, `scripts/minimal8_harness.py`, `docs/user/README.md`, `scripts/README.md`
- Reference-grid configuration and transform resolution are now shared through
  dedicated ingest-side helpers instead of living inside the slicing module,
  which makes the grid module read more honestly as geometry/rendering code.
  - Important identifiers: `scripts/reference_config.py`, `scripts/reference_grid_types.py`, `scripts/reference_grid.py`, `docs/architecture/source-sheet-ingestion-model.md`
- The matcher now prepares source tiles once per run, bulk-reads pixel data,
  reuses exact-match bytes and features across all cells, and keeps the
  trimmed logical-mask rescue narrow enough to fix the real temple edge cases
  without perturbing the clean overworld solve.
  - Important identifiers: `scripts/reference_tile_match.py`, `tests/test_reference_tile_match.py`, `prototypes/minimal8-harness/reference-transforms/reference-overworld-island-title-screen.md`, `prototypes/minimal8-harness/reference-transforms/reference-polychrome-temple-courtyard.md`
- The docs now teach the intended ingest -> library -> runtime split instead
  of a fuzzier “everything through the harness” workflow, which should make
  future reference-ingest work more legible for new contributors and agents.
  - Important identifiers: `docs/architecture/README.md`, `docs/functional/README.md`, `prototypes/minimal8-harness/README.md`, `prototypes/minimal8-harness/reference-transforms/README.md`
