# v0.3.0 — 2026-05-29

**Build the data-backed party-menu reference scene and character ingest**

v0.3.0 stands up the party-menu character-stats reference workflow end to end:
it scaffolds the `minimal8-characters` tile family and a construction
attachment-set system, migrates the harness project config to a tile-family
array, extends the reference matcher to score multiple candidate sources and
variant-qualified colourway references, and lands the reviewed party-menu
reference plus a verifier that keeps the scene and its reference in sync. This
is a MINOR bump because it carries breaking data-contract and config renames
described in the dedicated breaking-changes bullet below.

- A new `minimal8-characters` tile family scaffolds the separate Characters
  surface, with its own constructions plus a construction attachment-set
  system (`ConstructionAttachmentSet`, `load_attachment_manifest`,
  `attachment_sets_by_target`) so character heads and shared bodies compose as
  attachable variants over a base construction.
  - Important identifiers: `prototypes/minimal8-harness/tile-families/minimal8-characters/`, `attachments.json`, `constructions.json`, `family.json`, `scripts/tile_families.py`
- The party-menu character-stats screen now ships as a tracked scene with its
  reviewed reference handoff and a sync verifier, so drift between the scene
  selections and the reviewed reference fails a test instead of going unnoticed.
  - Important identifiers: `prototypes/minimal8-harness/scene-templates/party_menu_character_stats.json`, `prototypes/minimal8-harness/reference-transforms/reference-party-menu-character-stats.json`, `reference-party-menu-character-stats.md`, `tests/test_party_menu_reference_sync.py`
- The reference matcher now compares the recovered reference cells against one
  or more candidate source sheets, preserves per-candidate source provenance,
  reports a `MatchReport` with available source variants, and resolves
  variant-qualified colourway references so a mixed-family screen can confirm
  either a semantic tile or a raw source-sheet cell.
  - Important identifiers: `scripts/reference_tile_match.py`, `MatchSourceSpec`, `MatchReport`, `tests/test_reference_tile_match.py`
- BREAKING: data-contract and config renames land in one bump. The harness
  project key `tile_family` (object) becomes `tile_families` (array) with a new
  `default_tileset`; the reference-grid `RunSettings` field `scale` becomes
  `recovered_tile_scale`; `SourceTile`/`LoadedSourceSpec` gain required source
  and variant fields; and the construction-placement helpers take required
  positional params.
  - Important identifiers: `prototypes/minimal8-harness/project.minimal8.json`, `scripts/reference_grid.py`, `scripts/reference_tile_match.py`, `scripts/tile_families.py`, `scripts/minimal8_harness.py`
- Reference-grid guide rendering is reworked into a dedicated chrome/label-fit
  layout that scales guide overlays independently of the recovered-tile debug
  sheet, and the runtime gains a documented tile-genesis provenance model for
  tracing resolved tiles and stamps back to their promoted source.
  - Important identifiers: `GuideChrome`, `GuideCanvasLayout`, `--guide-render-scale`, `docs/architecture/runtime-tile-genesis-and-provenance.md`, `scripts/reference_grid.py`
