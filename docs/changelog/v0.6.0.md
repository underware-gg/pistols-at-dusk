# v0.6.0 — 2026-05-30

**Migrate all scenes off box and delete the legacy box subsystem**

v0.6.0 completes the box-to-parametric_frame migration: it adds a runtime
layout entity-op handler, authors the `glyph_stone` frame kit, moves every room
scene template onto frame entity + floor fill ops rendering pixel-identical to
the box baseline, then deletes the ~1150-line legacy box subsystem. This is a
breaking data-contract change: any scene template or project config using
`kind: box` or a `box_styles` block is no longer valid.

- Hand-authored layouts can now place a runtime entity op (`{kind: entity,
  construction, x, y, params, variant_id}`) that expands to stamps via the
  project's tile library, giving the migration its placement primitive without
  the template-mode expression machinery.
  - Important identifiers: `EntityOp` in `scripts/scene_templates.py`, `_apply_entity_op` and `_make_layer_op_handlers` in `scripts/minimal8_harness.py`, `expand_entity_stamps`
- A new `ui.frame.glyph_stone` parametric_frame kit provides the
  thin-corner frame analogue of the old `glyph_stone_frame` box style, with
  flip-derived corners and edges referenced directly by tile id so no
  `tiles.json` compose bindings are required.
  - Important identifiers: `prototypes/minimal8-harness/tile-families/minimal8/constructions.json`
- The temple_sanctum, causeway, twin_chambers and sanctum templates now build
  their rooms from frame entities plus separate floor fills (interior inset by
  the corner extent), rendering pixel-identical to the box baseline; the
  scene-expansion tests assert on resolved frame entities via
  `expand_scene_runtime`, and the migrated `outer_style`/`stem_style`/
  `bridge_style`/`inner_style` params are re-documented honestly as a vestigial
  field plus presence-only toggles.
  - Important identifiers: `prototypes/minimal8-harness/layouts/temple_sanctum.json`, `prototypes/minimal8-harness/scene-templates/causeway.json`, `prototypes/minimal8-harness/scene-templates/twin_chambers.json`, `prototypes/minimal8-harness/scene-templates/sanctum.json`, `tests/test_scene_expansion.py`
- The legacy box subsystem is deleted in full: this breaks any scene template or
  project JSON that still uses `kind: box` or a `box_styles` block, which must
  migrate to frame entities and floor fills.
  - Important identifiers: `apply_box`, `render_box_style_image`, `resolve_box_style`, `build_box_style_catalog`, `inspect_box_styles` (removed from `scripts/minimal8_harness.py`), `BoxOp` (removed from `scripts/scene_templates.py`), the `box_styles` blocks in `prototypes/minimal8-harness/project.minimal8.json` and `prototypes/minimal8-harness/project.minimal8.2bit.json`, removed `prototypes/minimal8-harness/layouts/box_style_gallery.json`, `tests/test_minimal8_harness.py`
- The contributor and prototype docs are realigned from the box model to frame
  kits so the documented surface matches the shipped one.
  - Important identifiers: `docs/architecture/construction-system.md`, `docs/functional/README.md`, `prototypes/minimal8-harness/README.md`
