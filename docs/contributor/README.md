# Contributor Documentation

This layer is the home for everyone working in the repo — humans and agents both. The bootstrap ([AGENTS.md](../../AGENTS.md)) routes you here; everything you need to know about *how* to contribute lives in this layer.

## Layer Index

- [Contributing](../../CONTRIBUTING.md) — baseline contributor rules and entry point
- [Contributor Process](process.md) — shared contributor workflow, verification, and hook usage
- [Release Workflow](release-workflow.md) — how dev work becomes latest versions and stable releases
- [Agent Instructions](agents.md) — contributor guidance for agents working in this repo
- [Working Rules](working-rules.md) — code design, canonical sources of truth, review workflow, change discipline
- [Repo Structure](repo-structure.md) — repo layout, ownership rules for generated outputs, scratch conventions
- [Documentation Standard Adoption](documentation-standard.md) — adoption notes and current maturity for the Agent-Ready Documentation Standard
- [Standards](../standards/README.md) — versioning, changelog, commit-message, and canary standards

## Where To Start

- New to the repo? Read [repo-structure.md](repo-structure.md) and [working-rules.md](working-rules.md).
- Touching docs? Read [documentation-standard.md](documentation-standard.md) before changing them.
- Shipping a version or stable release? Read [release-workflow.md](release-workflow.md) and the [Standards layer](../standards/README.md).
- Setting up local hooks and verification? Read [process.md](process.md).
- Working as an agent? Read [agents.md](agents.md).
