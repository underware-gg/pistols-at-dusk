# Mini Medieval

Vendor asset pack by **VEXED**, sourced from the Mini Medieval Bundle on itch.io.

- Source: https://itch.io/s/116731/mini-medieval-bundle
- Tile size: 8x8
- Style: pixel art, top-down
- Intended use: medieval RPG / RTS / TBS game development

## Pack layout

The bundle is six packs; each lives in its own subfolder:

| Folder | Pack |
| --- | --- |
| `default/` | Mini Medieval - 8x8 Top-Down (RPG / RTS / TBS) Assets (base pack) |
| `desert/` | Desert Expansion Pack |
| `ocean/` | Ocean Expansion Pack |
| `arctic/` | Arctic Expansion Pack |
| `kingdom/` | Kingdom Interior Expansion Pack |
| `user-interface/` | User Interface (UI) Expansion Pack |
