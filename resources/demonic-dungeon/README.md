# Demonic Dungeon

Vendor asset pack by **VEXED**, sourced from the Demonic Dungeon Bundle on itch.io.

- Source: https://itch.io/s/119323/demonic-dungeon-bundle
- Tile size: 16x16
- Style: minimal roguelike pixel art, top-down
- Intended use: roguelike / dungeon-crawler game development

## Pack layout

The bundle is seven packs; each lives in its own subfolder:

| Folder | Pack |
| --- | --- |
| `default/` | Demonic Dungeon - 16x16 Roguelike Top-Down Assets (base pack: hero characters, items, monsters) |
| `haunted-temple/` | Haunted Temple Expansion |
| `frozen-cavern/` | Frozen Cavern Expansion |
| `magma-maze/` | Magma Maze Expansion |
| `arid-underground/` | Arid Underground Expansion |
| `building-interior/` | Building Interior Expansion |
| `user-interface/` | User Interface (UI) Expansion |
